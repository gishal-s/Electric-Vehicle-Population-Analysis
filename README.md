# Electric Vehicle Population Analysis using Tableau

## Project Overview
This project explores Electric Vehicle (EV) population data using Tableau. The objective is to analyse EV registration patterns, identify popular manufacturers and models, compare vehicle types, and understand electric vehicle trends through interactive visualisations.

## Dataset Overview
- **Dataset:** Electric Vehicle Population Data
- **Records:** 166,800 rows in the original dataset
- **Columns:** 17
- **Geographical focus:** Primarily Washington State, USA

### Important Attributes
- Make and Model
- Model Year
- Electric Vehicle Type
- Electric Range
- Base MSRP
- County, City and State
- CAFV Eligibility

## Tools and Technologies
- Tableau – Data visualisation and dashboard development
- Microsoft Excel – Data inspection and preparation
- CSV – Dataset format

## Project Objectives
- Analyse the distribution of Battery Electric Vehicles (BEV) and Plug-in Hybrid Electric Vehicles (PHEV).
- Identify the most popular EV manufacturers and models.
- Explore EV registration trends by model year.
- Analyse geographical distribution.
- Understand electric range distribution.
- Build an interactive Tableau dashboard.

## Dashboard Features
- Total EVs and other KPI indicators
- EV Type Distribution
- Top 10 EV Manufacturers
- EV Population by Model Year
- EV Geographical Analysis
- Electric Range Distribution
- Top 10 EV Models
- Interactive filters for year, manufacturer, vehicle type, CAFV eligibility and location.

## Screenshots
Dashboard and individual visualisation screenshots are available in the `Screenshots` folder.

## Key Insights
- Battery Electric Vehicles represent the larger share of the dataset.
- Tesla is one of the leading manufacturers.
- Model Y and Model 3 are among the most represented EV models.
- The dataset provides insights into EV registration trends and electric range distribution.

## Future Scope
- Forecast future EV population trends.
- Integrate EV charging station data.
- Perform deeper geographical analysis.
- Improve data quality and handle missing values.
- Explore predictive analytics using Python and Machine Learning.
